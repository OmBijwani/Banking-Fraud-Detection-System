Security Logs

Fraud Detection Engine

Conditional rulesets implemented to parse transactions and isolate financial anomalies.

High Value Intercept
amount > 200000

Flags any transfer exceeding $200,000 USD. Heavy transaction volumes warrant manual supervisor review.

Empty Source Origin
oldbalanceOrg == 0

Flags transfers initiated from origin bank accounts that start with a zero-dollar balance. Common in laundering.

Sender Balance Cleared
newbalanceOrig == 0

Flags transactions that drain the entirety of the sender account. Fraudsters aim to extract maximum value.

High-Volume Cash-Out
type == CASH_OUT AND amount > 150000

Isolates large CASH_OUT operations above $150,000 USD. Cash out is the primary pathway to extract liquid funds.

About Project

Technical details, developers, and context behind the Banking Fraud Detection System.

Project Description

This system implements a comprehensive pipeline designed to identify fraudulent transactions within synthetic mobile banking logs. The project loads high-volume datasets from transactions.csv, performs extensive data cleaning and standardization, and loads the records into an optimized SQLite database.

Once database records are structured, SQL queries parse statistics and aggregate transactions. The system applies a multi-layered detection rule logic (value thresholds, account balance checks, and transaction correlations) to isolate fraudulent items.

Finally, audit logs are saved as reports, and descriptive matplotlib plots are exported to provide analysts with comprehensive visual insight into systemic vulnerabilities.
